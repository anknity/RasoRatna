# SHREE RaSo RATNA — Manpower Supply & Workforce Support Services

Official corporate website for **SHREE RaSo RATNA**, a Registered Micro Enterprise under the Ministry of MSME, Government of India (Udyam Registration No.: **UDYAM-JH20-0143778**).

Serving hospitals, corporate offices, warehouses, logistics depots, educational campuses, and industrial facilities across **Bihar & Jharkhand** (Patna & Ranchi hubs).

---

## 🚀 Live Site & Deployment

- **Hosted on:** [Netlify](https://www.netlify.com/)
- **Repository:** `https://github.com/anknity/RasoRatna.git`

---

## 🛠️ Tech Stack

- **Framework:** React 18 + TypeScript + Vite
- **Routing:** React Router v7 (SPA with Netlify rewrite rules)
- **Animations:** Framer Motion
- **Icons:** Iconify (`@iconify/react`)
- **Styling:** Custom CSS Design System (Dark Forest Green `#0d1f17` + Vibrant Lime `#9bde4a` + Ivory/Off-white `#f5f8f5`)
- **Media:** 1080p AI Video Background & Industry Photography generated via Google Flow (Nano Banana Pro / Veo)

---

## 📂 Project Structure

```
shree-ratna/
├── netlify.toml               # Netlify build configuration & SPA rewrites
├── public/
│   ├── _redirects             # SPA route rewrites for client-side routing
│   ├── images/                # Real-world workforce & sector photography
│   └── videos/                # 1080p cinematic hero background video
├── src/
│   ├── components/            # Hero, Navbar, Sectors, Services, About, Stats, WhyUs, Contact, Footer
│   ├── pages/                 # HomePage, ServicesPage, SectorsPage, AboutPage, WhyUsPage, ContactPage
│   ├── App.tsx                # BrowserRouter & route definitions
│   └── main.tsx               # Application entry point
├── package.json
└── vite.config.ts
```

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build locally
npm run preview
```
